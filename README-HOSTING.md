# ☁️ سورس سوبارو — نسخة الاستضافة المجانية (Render)

السورس بيشتغل 24/7 على استضافة **Render المجانية** (750 ساعة بالشهر = تكفي شهر كامل 24/7)، وبدون بطاقة بنكية.

## ⚠️ ملاحظات مهمة قبل ما تبدأ
- **النسخة المجانية بتنام:** خدمة Render المجانية بتنام بعد 15 دقيقة بدون زيارات — عشان هيك في خطوة **UptimeRobot** تحت، بيضرب رابط الخدمة كل 5 دقائق وبيخليها صاحية على طول.
- **ملفات السورس بتنمسح مع كل إعادة تشغيل** على الاستضافة — عشان هيك هالنسخة بتستخدم **جلسة نصية** (`SESSION_STRING`) بدل ملف `subaru.session`، وملفات مثل `schedules.json` و `points.json` بتنحفظ بالذاكرة بس وبتنمسح عند إعادة التشغيل. الجداول والنقاط اللي بتعملها من تيليجرام بعد التشغيل بتضل شغالة طول ما الخدمة شغالة، بس إذا انطفت الخدمة ورجعت، لازم تعيد الجداول. **إذا بدك حفظ دائم، استخدم نسخة الجهاز.**
- **الأمان:** نفس حدود الأمان تبع النسخة العادية (تأخير 10–15 ثانية، حد يومي 100 عضو). اكتب `.امان` بأي وقت لتشوف التقرير.

---

## الخطوة 1 — جيب API_ID و API_HASH (5 دقائق)
1. افتح https://my.telegram.org/apps وسجّل دخول برقمك (الكود بيوصلك داخل تيليجرام).
2. املأ النموذج: App title = `Subaru`، Platform = `Desktop`، وباقي الحقول أي شي.
3. انسخ `api_id` و `api_hash` — بتحتاجهم بالخطوات الجاية.

## الخطوة 2 — ولّد الجلسة النصية على جهازك (مرة وحدة)
1. على جهازك، انسخ ملف `.env.example` وسمّيه `.env` وحط فيه `API_ID` و `API_HASH`.
2. ثبّت المكتبات:
   ```
   pip install telethon python-dotenv
   ```
3. شغّل:
   ```
   python get_session.py
   ```
4. بيطلب منك رقم هاتفك، وبعدين الكود اللي بيوصلك على تيليجرام.
5. بيطلع لك نص طويل — **انسخه كامل واحتفظ فيه**، هذا هو `SESSION_STRING`. لا تشاركه مع حدا أبداً.

## الخطوة 3 — ارفع الكود على GitHub
1. اعمل ريبو جديد على https://github.com/new (سمّيه مثلاً `subaru-source`)، وخليه **Private** أفضل.
2. ارفع كل ملفات هالمجلد عليه (من صفحة الريبو: Add file > Upload files)، **ما عدا** ملف `.env` وملفات `*.session` — هدول ما لازم ينرفعوا أبداً.
3. تأكد إن ملف `render.yaml` موجود بالريبو.

## الخطوة 4 — شغّله على Render (مجاني)
1. اعمل حساب على https://render.com (سجّل دخول بحساب GitHub تبعك).
2. من لوحة التحكم: **New > Blueprint**، واختار ريبو `subaru-source`.
3. Render بيقرأ `render.yaml` وبيعمل خدمة `subaru-source` — اضغط **Apply**.
4. بعد ما تنعمل الخدمة، روح على **Environment** وحط المتغيرات:
   - `API_ID` = الرقم من الخطوة 1
   - `API_HASH` = النص من الخطوة 1
   - `SESSION_STRING` = النص الطويل من الخطوة 2
   - `BOT_TOKEN` = توكن البوت من @BotFather (اختياري)
5. اضغط **Save Changes** — الخدمة بتعمل Deploy تلقائياً، وبتشوف بالـ Logs:
   ```
   ✦ سورس سوبارو شغال ✦
   ```
6. جرّب من تيليجرام: اكتب `.فحص` بأي محادثة — لازم يرد عليك برسالة الفحص.

## الخطوة 5 — خلّيه صاحي 24/7 (UptimeRobot — مجاني)
1. اعمل حساب على https://uptimerobot.com (مجاني).
2. **Add New Monitor**، النوع **HTTP(s)**، وحط رابط خدمتك من Render (مثلاً `https://subaru-source-xxxx.onrender.com`).
3. خلي الفترة **5 minutes** واحفظ.
4. هيك كل 5 دقائق بيضرب الرابط، والخدمة ما بتنام أبداً.

## إذا صار خطأ
- **الخدمة ما بتشتغل / بتطفي:** شوف **Logs** في Render — إذا مكتوب `FloodWait`، ريح الحساب يوم.
- **`.فحص` ما بيرد:** تأكد إن `SESSION_STRING` منسوخ كامل بدون مسافات زيادة، وإن الخدمة حالتها **Live** في Render.
- **الخدمة نامت رغم UptimeRobot:** تأكد إن رابط المراقبة هو رابط الخدمة الصحيح وإن المراقبة مفعّلة.
- **الجداول والنقاط انمسحت:** هذا طبيعي بالنسخة المجانية بعد إعادة التشغيل — أعد الجداول بأمر `.جدولة`، أو استخدم نسخة الجهاز إذا بدك حفظ دائم.
